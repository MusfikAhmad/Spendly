# Spendly – Android app
1. Create a new GitHub repo and upload everything in this folder (keep the .github folder).
2. Open the repo → Actions → "Build Android APK" → wait ~5 min.
3. Download the "Spendly-APK" artifact, unzip, send app-debug.apk to your phone and install (allow "install unknown apps").

No GitHub? Host the www/ folder on any HTTPS site (e.g. Cloudflare Pages), open it in Chrome on Android → ⋮ → "Install app".
